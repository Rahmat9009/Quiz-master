# 🎯 Quiz Master

A modern full-stack quiz platform built with **React**, **TypeScript**, **Node.js**, and **PostgreSQL**, allowing users to create, manage, and take quizzes through an intuitive and responsive interface.

## 🌐 Live Demo

https://quiz-master-mz2u.onrender.com

---

## ✨ Features

- 🔐 User Authentication
- 📝 Create and manage quizzes
- ❓ Multiple-choice questions
- 📊 Quiz scoring and results
- 🎨 Responsive and modern UI
- ⚡ Fast React + Vite frontend
- 🗄️ PostgreSQL database
- 🔄 REST API backend
- 🤖 AI Chat Assistant integration
- 🔒 Secure authentication and protected routes

---

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/Rahmat9009/Quiz-master.git
cd Quiz-master
````

### Install dependencies

```bash
npm install
```

### Configure environment variables

Create a `.env` file in the project root.

Example:

```env
DATABASE_URL=your_database_url
JWT_SECRET=your_secret
```

### Run the development server

```bash
npm run dev
```

---

## 📦 Build for Production

```bash
npm run build
```

Run the production server:

```bash
npm start
```
